# WIlDev

A preserved GUI prototype and early interface experiment related to the WillDev automation work.

This repository is kept separate from the newer backend project because it represents an earlier presentation layer rather than the current service architecture. It is useful as a visual reference and historical design snapshot, not as the production publishing system.

## Repository boundary

- GUI-focused prototype work.
- No live publishing authorization.
- No production credentials.
- No guarantee that the legacy interface matches the current WillDev API.

For the active backend and AI content workflow, use:

https://github.com/example-org/WillDev

## Safe handling

Keep any local configuration outside Git. Do not add passwords, access tokens, cookies, provider keys, or generated runtime state to this historical repository.
